# NXMap callback 원본 정적 계약 검토

report43에서 데이터로 다시 확인한 NXMap 상수들의 callback을 추적한다. 원본 바이트, Ghidra ASM/C, 실제 간접 호출자의 인자 준비·반환값 사용과 초기 selector 문자열을 읽기 전용으로 대조한다.

독립 교차검토 실패를 승인으로 처리하지 않는다. 이번 단계에는 신규 커널/실행/검증 프로그램 작성이나 emulator 실행이 없다. 새로운 교차검토 요청으로 기존 안전성 판정을 우회하지 않는다. Python은 주소·상수·부호 확장·크기·해시 계산과 진단 자료 기록에 사용한다.

정적 callback 계약과 도구 해석 차이를 기록하되, Objective-C runtime 전체·동적 method 효과·NXMap 전체 수명·정확한 원본 헤더·GCC 2.7 ABI 검증을 완료했다고 선언하지 않는다. 전체 미완료 범위는 이전 보고서 목록을 유지한다.
