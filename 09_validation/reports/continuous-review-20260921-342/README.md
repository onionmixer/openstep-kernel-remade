# 342차 정적 검토 — Subroutine does not return 간접 jump-table 후보 4개

0x0014e844, 0x0014f1b8, 0x001ae348, 0x00168564의 간접 JMP 테이블을 원본 mach_kernel 바이트에서 Python으로 해독했다.

처음 세 함수의 테이블은 각각 5개·6개·5개 엔트리이며, 테이블 대상을 직접 CFG 시작점에 추가하면 각각 한 개의 RET 블록에 도달한다. 따라서 이 세 경고는 간접 점프를 무시한 CFG 모델의 한계로 전체 비반환을 뒷받침하지 않는다.

0x00168564는 정규화 인덱스 0..13의 14개 테이블 엔트리를 가지며, 0x00168660 한 개, 0x00168671 네 개, 0x001686a8 아홉 개로 분배된다. 이 함수의 return 동작은 이 테이블 대조만으로 확정하지 않는다.
