# NXMap 삽입·교체·삭제·확장의 정적 분석 범위

report44의 callback 계약에서 이어 원본 NXMapInsert, NXMapRemove, 확장 helper, reset/free와 allocator 연결을 읽기 전용으로 검토한다. 어셈블리·디컴파일·원본 명령 바이트·호출 위치를 구분하고, 계산은 Python으로 수행한다.

이번 단계에는 새 emulator 시험이나 복원/검증 프로그램 구현이 없다. 코딩 전 독립 교차검토 미수신 조건을 유지하며 이전 도구의 안전성 판정을 우회하는 재요청을 하지 않는다. 후속 시험 후보가 생겨도 실제 실행 결과로 기록하지 않는다.

계약·호출 순서의 정적 근거와 실행 미검증 전제를 함께 남긴다. 사용자 callback 부작용, 잘못된 입력의 실제 도달 가능성, allocator 실패/경합, native 실행, GCC 2.7 빌드와 전체 원본 분석 완료를 주장하지 않는다.
