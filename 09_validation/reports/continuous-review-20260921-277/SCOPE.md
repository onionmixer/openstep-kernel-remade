# 범위

원본-derived full-pass5 decompiler warning export와 260–276차 원본-byte evidence 및
checkpoint만 사용했다. Python으로 category record·instance·fragment 수, reviewed-entry
mapping 및 각 checkpoint의 original-binary·tracked-file SHA-256을 검증했다.

범위는 warning category의 byte-review coverage와 checkpoint 무결성이다. warning 정확성,
ABI, parameter storage, return convention, runtime 의미는 범위 밖이다.
