# 전체 분석 단위별 의미 검토 원장 계획

전체 목표를 유지하며, 자료 확보와 의미 검증의 혼동을 방지하는 원장을 만든다. 이번 과제는 문서·메타데이터 관리이며 report42에서 보류된 PD 실행 계획을 재시도하거나 승인한 것으로 취급하지 않는다.

## 식별과 상태

- 대상 binary SHA-256, architecture, Ghidra export 식별자, entry address를 묶어 분석 단위를 식별한다. 일반 함수와 인위적 fragment를 분리하고 entry 중복·범위·본문 크기를 검사한다. 단위 수를 원래 함수 수나 의미 검증 coverage 비율로 사용하지 않는다.
- Ghidra export 상태와 경고, IDA 주소별 결과를 별도 필드로 둔다. IDA 요청 주소가 현재 Ghidra entry와 다르면 별도 목록에 보존한다. Ghidra 성공으로 IDA 실패를 지우지 않는다.
- 기본 의미 검토 상태는 `not_assessed_by_ledger`다. 이는 해당 함수가 역사적으로 전혀 분석되지 않았다는 뜻이 아니라 기존 증거가 아직 이 원장에 정식 연결되지 않았다는 뜻이다.
- 수동으로 확인한 제한된 증거에는 `bounded_evidence_indexed`와 구체적 scope, 근거 파일·해시, 미해소 의무를 붙인다. 단순 보고서/주소/함수명 검색으로 승격하지 않는다. `full_semantics_complete`는 이번 초기 원장 전 항목에서 false다.
- 문서 속 entry 주소 후보는 탐색용 별도 index로만 보존한다. 부정 사례·계획·실패 기록도 주소를 포함할 수 있으므로 이것을 검증 증거로 취급하지 않는다.

## 입력과 보존

최종 full-pass5 함수 인벤토리, 함수별 ASM/C/JSON, 경고 목록, IDA index/failures 및 성공 pseudocode를 현재 해시와 보존 manifest에 대조한다. report41/42의 checkpoint와 등록할 제한적 근거도 확인한다. 이전 원본·DB·export·보고서는 수정하지 않는다. 출력과 코드 수정은 이번 디렉터리만 사용한다. 모든 계산은 Python으로 한다.

## 구현 전 검토와 검증

사용자 요구에 따라 별도의 독립 Codex 계획 교차검토 의견을 받은 뒤 원장 관리 코드를 작성한다. root는 의견을 현재 파일과 대조한다.

검증은 전체 source entry 집합과 원장 집합의 일치, 일반 함수/fragment 분리, 경고·IDA 실패 원형 유지, 본문 byte range의 독립 집계, 누락/중복/허위완료/증거 링크 변조 거부를 포함한다. 생성기를 실행하지 않고 원장을 읽는 consumer를 따로 둔다. 같은 입력에서 재생성한 파일 해시를 비교한다. 이러한 metadata 검사가 함수 의미를 증명한다고 표현하지 않는다.

## 남겨 둘 범위

전체 함수의 과거 증거 수동 등록, 계약·타입·ABI·분기·오류·동시성 의미 검증, native 실행, PD 후속 동적 검증, source mapping, GCC 2.7 실컴파일·링크·부팅, SPARC와 후속 architecture 의무는 계속 미완료다. 원장 초기화 완료를 전체 분석 완료로 선언하지 않는다.

## 현재 조사에 따른 계획 보완 — 아직 구현하지 않음

독립 검토가 안전성 판정으로 종료되어 생성기/consumer를 작성하지 않았다. 아래 사실은 읽기 전용 집계로 확인했으며 [inventory-comparison.json](inventory-comparison.json)에 남겼다.

- IDA 성공 주소 중 `1cde80`과 `1cdea0`은 현재 함수가 아닌 데이터다. raw 도구 성공과 현재 함수의 pseudocode 확보를 분리해야 한다.
- 인위적 분석 조각은 IDA 실패가 아니라 요청되지 않은 상태다.
- Ghidra 경고가 없는 IDA 실패가 있으므로 경고만으로 후속 목록을 만들지 않는다.
- 참고 헤더의 직접 선언과 형태가 비슷하다는 추론을 구별한다. 이번에 확인한 NXMap 상수는 기존에 인용한 hashtable2.h에 직접 선언되어 있지 않다.

이 조사 산출물은 의미 검토 원장을 생성한 것이 아니다. 전체 단위별 과거 증거 등록은 여전히 필요하다.
