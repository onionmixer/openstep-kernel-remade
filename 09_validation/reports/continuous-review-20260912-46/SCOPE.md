# NXMap 생성·순회·비교의 정적 검토

원본 생성 함수, capacity 보조 함수, count/iterator/compare 본문을 읽기 전용으로 대조한다. 실제 함수 명령과 해석, Python으로 계산한 크기/경계, 아직 실행하지 않은 전제를 구분한다.

독립 계획 검토 미수신에 따른 코딩 전 조건을 유지한다. 이번 단계에는 새 emulator 시험, 복원 소스, 실행/검증 프로그램 구현 또는 DB 수정이 없다. 진단 계산과 근거 JSON 기록만 Python으로 수행한다. 전체 원본 분석·native 실행·GCC 2.7 빌드 완료를 주장하지 않는다.
