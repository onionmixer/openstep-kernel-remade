# 정적 검토 범위: ObjC 모듈의 상위 로드·종료 경로

이 단계는 report52의 등록·해제 분석을 호출자와 보존된 참조 소스에 연결한다.

- 원본 명령과 보존된 Ghidra ASM/C/metadata를 대조한다.
- `kern_serv_load_objc`, `kern_serv_shutdown`, 부팅 등록 반복문, 로그 정리 및 Mach-O 섹션 검색 함수의 본문을 검토한다.
- Darwin 참조 소스와 OPENSTEP 헤더는 대응 근거이지 원본 소스 동일성의 증명이 아니다.
- 계산·주소 처리·해시·집계는 Python만 사용한다.
- 독립 계획 검토가 새로 확보되지 않았으므로 새 검증 프로그램·동적 실행·커널 구현은 하지 않는다. 기존 감사기의 읽기 전용 디코더만 재사용한다.
- 결과는 호출 순서와 본문 수준의 정적 계약이다. 전이적 호출 그래프, 실제 부팅, 메모리 수명 전체 또는 GCC 2.7 호환성의 완료 판정이 아니다.
