# 87차 — OPENSTEP 원본 disk 메서드와 제출 계약

사용자의 최신 범위 제한을 유지한다. 다른 프로젝트의 코드와 `01_resources`,
복원 중인 `07_kernel`을 열거나 비교하지 않는다. 원본 x86 `mach_kernel`,
그 바이너리의 Ghidra full-pass5 출력·참조·메타데이터와 원본 분석 기록만 사용한다.
기존 외부 소스 비교는 현재 동작의 증거가 아니다.

이번 경계는 86차 disk selector 후보의 정적 소유 class, errno 변환,
read/write wrapper ABI, ObjC lookup/super 호출, 직접 연결된 매개변수 변환과
SCSI 요청 제출 본문이다. 실제 receiver의 생성·등록, category 연결·초기화,
enqueue 이후 완료와 장치 동작은 별도의 미해결 항목으로 유지한다.

Ghidra 스킬의 함수 본문·디컴파일·참조 대조 절차를 이미 보존된 export에 적용했다.
원본 DB·바이너리·export와 이전 확정 보고서는 수정하지 않는다.
디컴파일러의 타입·void 반환·간접 호출 표현을 원본 명령보다 우선하지 않는다.

독립 계획 교차검토 결과를 새로 받지 못한 상태를 통과로 바꾸지 않는다.
과거 실패 요청을 재시도하거나 우회하지 않는다. 새 검증 프로그램·에뮬레이터·커널
구현을 작성하지 않으며, inline Python의 원본 바이트 디코드·유한 정수 계산과
증거 JSON·문서 기록에 한정한다. 모든 계산은 Python, 모든 파일 변경은 apply_patch다.
동적 실행·소스 복원·빌드·포팅은 수행하지 않는다.

완료 판정은 이번 지역 검토 산출물에 한정한다. 전체 원본 분석 완료를 선언하지 않는다.
