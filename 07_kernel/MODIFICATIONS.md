the original version used and the change. A "restoration edit" changes
reference source so that it compiles to the bytes of the original OPENSTEP
4.2 kernel (mk-183.34.4, x86 `mach_kernel` SHA-256
`33469393c0843fc741942c3ae9d91d838467d72abd647dcf2e5bf499a3f14890`); the
rules are in `02_plan/RECONSTRUCTION_PLAN.md` section 19 (decision D014).
The result reproduces the original object code; it is not claimed to be the
historical source text.
